# API di reporting

Questo articolo illustra come utilizzare [!DNL Customer Journey Analytics Reporting API] per implementare il seguente [caso d&#39;uso per l&#39;esportazione dei dati](overview.md):

- Integrazione dell’applicazione personalizzata

## Introduzione

[!DNL Customer Journey Analytics Reporting API] consente di recuperare le stesse dimensioni e metriche elaborate disponibili in Analysis Workspace a livello di programmazione. Utilizza [!DNL Reporting API] per abilitare le applicazioni personalizzate, incorporare il reporting in strumenti interni o automatizzare il recupero dei dati di Customer Journey Analytics senza un&#39;esportazione manuale.

## Ulteriori informazioni

[!DNL Reporting API] utilizza lo stesso formato di richiesta e risposta di [!DNL Adobe Analytics] [!DNL Reporting API], ma utilizza un endpoint diverso. Se stai eseguendo la migrazione di integrazioni di reporting da [!DNL Adobe Analytics], consulta il flusso di lavoro di migrazione nella [Guida rapida](/help/getting-started/cja-getting-started.md) per ulteriori informazioni.

Per l&#39;autenticazione, gli endpoint disponibili e i limiti di richiesta correnti, consulta la [documentazione API di Customer Journey Analytics](https://developer.adobe.com/cja-apis/docs/).
