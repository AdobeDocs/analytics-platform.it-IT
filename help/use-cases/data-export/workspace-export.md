# Esportazione Workspace

Questo articolo illustra come utilizzare le opzioni di esportazione di Analysis Workspace per implementare il seguente [caso d&#39;uso per l&#39;esportazione dei dati](overview.md):

- Generazione di rapporti ad hoc e ricorrenti

## Introduzione

L’esportazione dei dati direttamente da Analysis Workspace consente ai singoli utenti di scaricare o inviare un progetto tramite e-mail senza configurare una destinazione cloud o una pipeline di dati.

## Ulteriori informazioni

Puoi scaricare un progetto, o parte di esso, da Analysis Workspace alla tua workstation come file PDF, CSV o JSON. I download sono solo ad hoc e sono limitati a 50.000 righe. Per ulteriori informazioni, consulta [Scarica sulla tua workstation](/help/analysis-workspace/export/download-send.md).

Puoi anche inviare un progetto tramite e-mail ad altri utenti dell’organizzazione, ad hoc o secondo una pianificazione. I report inviati tramite e-mail sono limitati a 400 righe. Per ulteriori informazioni, vedere [Invia ad altri utenti](/help/analysis-workspace/export/t-schedule-report.md).

Per un confronto di tutti i metodi di esportazione di Analysis Workspace, inclusa l&#39;esportazione di tabelle complete nel cloud, vedere [Panoramica sull&#39;esportazione](/help/analysis-workspace/export/export-project-overview.md).
